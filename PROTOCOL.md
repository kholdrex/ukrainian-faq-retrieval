# Protocol

Fixed before retrieval runs. Deviations are listed in CHANGELOG.md.

## Question

For Ukrainian FAQ answer retrieval in a question-answering assistant, how do lexical, dense, hybrid and
LLM-expanded retrievers compare as the answer collection grows, how much do their successes overlap, and what does
each cost in index time and query latency?

## Data

WebFAQ retrieval, Ukrainian configuration (`ukr-corpus`, `ukr-queries`, `ukr-qrels`), CC BY 4.0. Answers with identical
normalised text are merged; a query is relevant to the merged answer. `uafaq data` (seed 2026) draws 1000 test queries
from the test split and 200 development queries from the train split. Pools: 2000 and 10000 answers (all relevant
answers of the test queries plus random others) and the full de-duplicated collection. Development queries are used
only to check the pipeline on the full pool.

## Retrievers

- `bm25`: word BM25 (k1 = 1.2, b = 0.75), lower-casing and apostrophe normalisation, no stemming.
- `char`: TF-IDF over character 3–5-grams within word boundaries, sublinear tf.
- `mminilm`: paraphrase-multilingual-MiniLM-L12-v2, cosine similarity.
- `bge-m3`: BGE-M3 dense vectors via Ollama, cosine similarity.
- `rrf`: reciprocal rank fusion of `bm25` and `bge-m3`, k = 60, no tuning.
- `*_exp`: the same retrievers with the query followed by a short hypothetical answer generated by
  qwen2.5:7b-instruct (temperature 0, at most 96 tokens, fixed Ukrainian instruction).

## Endpoints

- Primary: nDCG@10 on the full pool for `rrf` vs the best single retriever, and `rrf_exp` vs `rrf`; 0.02 nDCG@10 is
  the smallest difference treated as practically relevant.
- Secondary: Recall@1, Recall@10, MRR@10 and Recall@100 for all retrievers and pools; overlap of top-10 successes of
  `bm25` and `bge-m3` (both / lexical only / dense only / neither); index build time, single-query latency (median
  and 95th percentile over 200 test queries, one query at a time, warm models), expansion latency.

## Statistics

Paired bootstrap over queries (2000 resamples) for differences in means; exact McNemar test for paired Recall@10
decisions of the primary contrasts.
